## About

**Butterscotch iOS 12** is an unofficial community port of [Butterscotch](https://github.com/ButterscotchRunner/Butterscotch), an open-source reimplementation of the GameMaker: Studio runner.

The goal is to make GameMaker: Studio games playable on devices running **iOS 12**, including older iPhones and iPads that cannot run modern iOS versions.

This port is experimental, and compatibility may vary depending on the game, its GameMaker version, and the device.

## Tested device

- **Device:** iPad Air (1st generation)
- **Operating system:** iOS 12
- **Application interface:** French

## Tested games and features

Tested on the author's iPad Air (1st generation) running iOS 12:

- [x] Undertale
- [x] DELTARUNE Chapters 1–2
- [x] Game audio
- [x] Save functionality
- [ ] DELTARUNE Chapters 3–5 — not tested; the author does not have a copy of that version.

Compatibility results are based on the author's own tests and do not guarantee that every game or device will work.

## Features

- iOS 12-focused port of the Butterscotch runner
- Support for older Apple hardware
- Game compatibility based on the upstream runner, subject to port-specific limitations
- Audio and save functionality tested on an iPad Air (1st generation)
- French application interface
- FFmpeg is not included, so in-game video playback is unsupported. FFmpeg integration was left out after repeated technical issues.

### Game files required

**You must provide your own game files.** This repository contains the port/runner, not the game data for Undertale, DELTARUNE, or any other commercial game. Butterscotch cannot run a game without the required files.

Please obtain games through official or otherwise legally authorized sources and use files you are legally entitled to use. This project does **not** distribute, link to, or provide instructions for obtaining pirated copies of games.

**This project does not promote piracy.** Please do not open issues or pull requests asking for copyrighted game files, unauthorized downloads, or links to pirated copies.

## Known limitations

- This is an experimental port, so crashes, graphical glitches, or performance issues may occur.
- Not every GameMaker: Studio game is guaranteed to work.
- Compatibility has only been tested on a limited set of hardware.
- FFmpeg is not included, so videos that depend on FFmpeg may not play.
- DELTARUNE Chapters 3–5 have not been tested because the author does not have that version.
- The original runner's compatibility limitations also apply. See the [upstream compatibility notes](https://github.com/ButterscotchRunner/Butterscotch#game-compatibility).
